# HackAlem FAQ Quiz — Telegram Web App

Готовый статический сайт-опросник на 5 вопросов, без Python, сборки и API-ключей.

## Файлы
- `index.html` — весь сайт (HTML/CSS/JS).

## Перед публикацией
Откройте `index.html` и в массиве `questions` замените тексты-заглушки на официальные вопросы, варианты ответов и правильные индексы.
`correct` — индекс правильного варианта, начиная с `0`.

## Публикация через Vercel
1. Распакуйте ZIP.
2. Загрузите `index.html` в корень вашего GitHub-репозитория (или импортируйте папку в Vercel).
3. В Vercel выберите проект/репозиторий и разверните как статический сайт. Build Command можно оставить пустым, Output Directory — `.`.
4. После деплоя получите HTTPS URL.

## Подключение к Telegram-боту
1. В BotFather настройте Web App / Menu Button и укажите HTTPS URL сайта (названия пунктов могут отличаться в интерфейсе).
2. Откройте Web App из вашего бота.
3. Внутри Telegram кнопка «Отправить результат в Telegram» вызывает `Telegram.WebApp.sendData(...)`.
4. Ваш бот должен обработать входящее `web_app_data` и сохранить/показать результат. Сам сайт не отправляет данные на сервер самостоятельно.

Важно: обычная кнопка/ссылка на сайт в Telegram не равна полноценному Web App. Для получения `sendData` нужен запуск внутри Telegram через настроенную Web App-кнопку, а на стороне бота — обработчик данных.

## Проверка
Откройте `index.html` локально или через Vercel. Пройдите 5 вопросов, завершите опрос. Вне Telegram результат скачивается JSON; внутри Telegram отправляется через `sendData`.
